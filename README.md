# cultura-softwaretechnik

Cultura – Softwaretechnik group project: language and cultural exchange, UML diagrams, documentation and Figma prototype.

## Project Overview

Cultura is a mobile app concept designed to connect people through language learning and cultural exchange. It aims to help users find language partners, discover cultural workshops and learn about different cultures through quizzes.

Developed as a four-student project for the Softwaretechnik module at FH Dortmund, the project covers requirements analysis, user personas, use case specifications, UML modelling and a Figma prototype.
